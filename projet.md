Crée une page web moderne et responsive, inspirée du style visuel de Snapchat (couleurs, icônes, simplicité), sans utiliser le logo ni prétendre être Snapchat.
Objectif de la page :
Informer l’utilisateur que le service de localisation partagée ne parvient pas à déterminer sa position automatiquement, et lui demander des informations complémentaires pour améliorer la précision.
Contenu et fonctionnalités attendues :
Message explicatif clair et rassurant
Indiquer que la localisation automatique n’a pas fonctionné
Expliquer que les informations demandées servent uniquement à améliorer la précision du service
Formulaire de précision manuelle avec les champs suivants :
Utilise-t-il un VPS / VPN / Proxy ? (Oui / Non)
Pays
Ville
Point de repère proche (immeuble connu, lieu public, monument, etc.)
Carte interactive (ex : OpenStreetMap ou Google Maps) :
Permettre à l’utilisateur de cliquer sur un point de la carte
Afficher un marqueur à l’endroit sélectionné
Récupérer automatiquement les coordonnées GPS (latitude / longitude)
Afficher ces coordonnées sous la carte
Bouton de validation
Texte clair : “Confirmer la position”
Vérifier que les champs essentiels sont remplis
Message de succès après validation
Message positif et rassurant (ex :
“✅ Position enregistrée avec succès. Merci pour votre aide, le service de localisation a été amélioré.”)
Contraintes techniques :
UI propre, fluide, mobile-first
Aucune donnée envoyée sans action explicite de l’utilisateur
Prévoir des commentaires clairs dans le code
Bonus UX (si possible) :
Animation légère lors de la sélection sur la carte
Icônes dans le ton de snap
Ton neutre et professionnel
